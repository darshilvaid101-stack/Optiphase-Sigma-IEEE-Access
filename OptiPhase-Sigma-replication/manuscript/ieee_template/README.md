# IEEE Access template files

These files come from the IEEE Access LaTeX template as received (`ieeeaccess.cls`, `IEEEtran.cls`, `bullet.png`,
`logo.png`, `notaglinelogo.png`). The class files are byte-identical to the template.

The two logos are stored under the capitalized names that `ieeeaccess.cls` requests (`Logo.png`, `notaglineLogo.png`).
The contents are unchanged. The class names them in its header code, and Overleaf is case-sensitive.

The sample photographs and the sample paper of the template are not used.

`src/build_manuscripts.py` compiles the IEEE manuscript from a staging copy with a CMYK accent colour in place of the
Pantone block, because tectonic runs XeTeX. The files here are not modified.
